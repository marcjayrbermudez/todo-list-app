# To-Do List App

A simple web app for planning daily tasks, built with **HTML, CSS, and JavaScript**.

## Features
- Add tasks with a **priority** (Low, Medium, High) and an optional **due date**
- Mark tasks as done, **edit** them, or **delete** them
- **Search** tasks and **filter** by All, Active, or Done
- Shows **overdue** tasks in red
- Counter of tasks left and a "Clear completed" button
- Tasks are **saved in the browser** (localStorage), so they stay after a refresh
- Works on phone and desktop

## How to run
Open `index.html` in Chrome or Edge. No installation needed.

## Files
```
index.html   page structure
style.css    design
script.js    app logic (adding, editing, filtering, saving tasks)
```

## What I learned
- Storing data as an **array of objects** and updating it with functions
- Using **if/else**, **loops** (`forEach`, `filter`), and **events** in JavaScript
- Saving data with **localStorage** using `JSON.stringify` and `JSON.parse`
- Using `textContent` instead of `innerHTML` for user input to keep the page safe
